# PaperFlow · 论文投稿进度小部件

Windows 桌面小部件，盯住多篇论文的投稿进度。同时显示粗进度条，点击阶段即可更新；无需注册应用账号，界面有中文和英文两版。

它是小部件而不是普通窗口：任务栏和 Alt+Tab 里都不会出现，程序待在系统托盘，双击托盘图标恢复，托盘菜单的 `退出` 才真正关闭。你自己打开的设置、论文资料等窗口照常有任务栏入口。

1.4.0 起产品名由 PaperProgress 改为 PaperFlow。首次启动会把 `%LOCALAPPDATA%/PaperProgress` 中的本机资料复制到 `%LOCALAPPDATA%/PaperFlow`，原目录保持不动，论文、修改记录和同步设备标识都不受影响。

## 使用

在[本仓库的 Releases 页面](https://github.com/pwya/paperflow/releases)下载最新的 `PaperFlow-<版本>-win-x64.zip`，完整解压到自己选择的文件夹，打开 `PaperFlow.Launcher.exe`。发行包自带 .NET 8；启动器使用 Windows 自带的 .NET Framework 4.x。面向 Windows 10/11 x64，尚未覆盖其他系统与 ARM 原生版本。源码构建需要 .NET 8 SDK。

程序没有购买代码签名证书，所以**第一次运行时 Windows 可能弹出蓝色的 SmartScreen 提示**（“Windows 已保护你的电脑”）。点“更多信息”，再点“仍要运行”即可；之后不会再问。介意这一点的话可以自己从源码构建。

- 右上角 `＋` 新增论文，自动生成七个阶段：开题、语料&数据整理、初稿、自修、在审、返修、收录。旧“投稿”的勾选直接显示为“在审”，进度保持原样。
- 每个阶段等权，自动显示完成数、百分比和粗进度条；无需返修时可在资料里选择跳过返修，分母相应调整。
- 标题最左侧的三个点表示优先级：三点为高，两点为中，一点为低；点击圆点直接切换，也可在论文资料里修改。
- 卡片右下角的论文设置按钮统一打开编辑资料、修改记录、上移下移、复制与归档，卡片本身不再放资料按钮。资料支持学科、语种、合作者、期刊、优先级、状态、下一步、开始日期、截止日期与备注；状态保存在资料中，不单独占据卡片空间。
- 按住论文标题、优先级圆点或卡片空白处拖动，根据高亮插入线放到另一篇论文之前或之后。放下后采用手动优先顺序并同步；筛选中隐藏的论文保留原位置，拖到列表边缘可自动滚动。勾选框和论文设置按钮不会触发排序。
- `论文选项` 集中搜索、筛选、排序和紧凑视图。`设置` 分成外观、字体与文字、视图与分页、同步与启动、关于与反馈五类。
- 界面语言在 设置 → 外观 → 界面语言，可选跟随系统、中文、English。切换语言只换显示：阶段名、状态、主题这些在文件里仍是原来的规范值，老配置和老同步记录完全兼容，两台语言不同的电脑也能正常同步。保存后挂件自动重启一次换成新语言。
- 外观里有五种排版风格、共 23 套主题：纸感（中性灰白、细进度条、阶段用圆点加文字）、柔光（米白暖色、大圆角、胶囊阶段）、夜航（深色玻璃，霜蓝取自 Nord 官方色值）、标签（阶段按类别分色）、极简（配列表布局）；原来的六套主题保留为“经典 · ”，老配置升级后外观不变。每行主题带三个色点预览，点一下立刻生效，也可以自定义主色、底色、不透明度、字体、进度条厚度。
- 布局可选卡片或列表：列表去掉卡片、只用分隔线，一屏能看更多篇。还能跟随 Windows 的浅色/深色设置，浅色主题会自动换成配对的深色主题。
- 背景图片：外观页里可以选一张本机图片当底（png/jpg/webp/bmp/gif），用“图片遮罩”和“背景不透明度”控制图片与文字的平衡。图片只在本机使用，路径不参与同步。
- 字号 9–36 只改文字大小，界面缩放 80%–200% 把文字和间距一起缩放，两个滑杆旁边实时提示当前窗口大约能显示几篇。文字不会随背景一起透明。
- 文字分三档——标题、正文、次要，每一档可以单独选字体、调字号比例和改颜色；留空就跟随基础字体和主题。自定义颜色会做对比度检查，太接近底色会直接提示。
- 勾选阶段后如果论文被“暂时隐藏的阶段”藏起来、或被分页挪走，底部会滑出一条提示条说明去哪了，并给“立即显示”或“翻到第 N 页”；设置里可以整个关掉。归档与复制也有对应提示。
- 反馈音效默认关闭。想开的话在 设置 → 视图与分页 → 音效：三档（关 / 只完成时 / 完成和取消都响）、三种音色（木质、清脆、水滴）、音量滑杆和三个试听按钮；勾满七个阶段有单独的奖励音。音效在内存里合成，不带音频素材，只在本机生效。
- 按阶段隐藏的论文不必去设置里改：挂件右上角的“显示隐藏 N 篇”点一下就能临时展开，它们会显示成灰底并带“已隐藏”标记，再点一下收回去，长期设置不受影响。
- `论文选项` 里的排序方式会保存在本机；不是“手动排序”时，顶部汇总会写明当前排序，方便判断两台的顺序为什么不同。拖动排序会自动切回“手动排序”。
- 字号和界面缩放滑杆旁边会实时提示“当前窗口大约能完整显示几篇论文”，还有一个可选的“调整时自动放大窗口”，打开后窗口按比例跟着长，最多占屏幕工作区的一半。
- 天数与阶段同行，窄窗口自动换行。下一步文字利用末行剩余空间显示，放不下时可悬停进度条查看完整内容，不再单独占一行。
- `置顶` 保持可见；拖动顶部标题栏或小部件空白处移动窗口并记住位置，拖动边缘调整大小。`×` 收起到托盘，双击托盘图标恢复；托盘菜单的 `退出` 才会完全关闭。左上角图标跟随主题色，系统图标保持固定。
- 设置中的开机启动可按需开启。桌面和开始菜单的入口也让程序自己放：设置 → 同步与启动 里勾选保存即可，托盘菜单的“放好桌面和开始菜单快捷方式”一次做好两个；它们指向固定启动入口，升级后不用重建。任务栏图标不能由程序自己钉，右键那个快捷方式选“固定到任务栏”就行。快捷键：`Ctrl+N` 新增，`Ctrl+F` 论文选项，`F12` 切换置顶。

## 跨电脑同步

从 1.2 升级时，请在各台电脑从托盘退出，再打开相同启动器更新到 1.3 或以上，以读取新增的优先级字段。旧版会拒绝不认识的新字段；已有历史事件不用修改。

多台电脑之间靠一个云盘同步文件夹交换数据。任何会自动同步文件的网盘都行，程序不需要专门支持某一家。把**完整发行包**解压到你选定的同步文件夹内，在各台电脑打开各自同步下来的 `PaperFlow.Launcher.exe`。启动器自动使用旁边的 `data` 文件夹，不要求各台电脑有相同盘符或用户名。建议把整个安装文件夹设为“始终保留在此设备上”。每台电脑使用同一份个人资料库；开发测试使用独立 `--data-dir`，不要用默认个人目录测试。

论文修改先保存到本机，每两秒尝试与共享文件夹交换记录；另一台电脑收到文件后自动刷新。离线也能编辑，联网后续传。网盘客户端暂停、离线或仍在下载时会有延迟，应用不能确认云端上传完成。页脚“同步文件夹已更新”仅代表应用已读写本地同步目录。

数据使用独立、不可变的修改文件。不同电脑同时修改不同字段或阶段可以合并；同时改同一字段按逻辑时钟、随机设备编号和事件编号确定一致结果，**不保证按现实时间最后一次修改胜出**。界面历史保留操作记录，底层事件保留修改值。损坏的远端文件保留并提示重试，其他有效修改继续同步。当前没有历史压缩功能；长期使用记录会逐渐增长。

各台电脑版本不同也不会互相丢数据：遇到本机不认识的新字段只跳过那一条，其余改动照常生效，原文件保留；整条记录来自更高版本时先存着不应用，升级后自动补上。状态栏会提示有多少条记录在等升级。

主题、字号、界面语言、更新提示、窗口位置、开机启动和路径属于各设备设置，不跨电脑同步。旧版本机资料在首次启动时自动写入新记录库。资料仅支持归档，不提供跨设备永久删除。

## 程序、资料与源码的边界

| 位置 | 内容 | 是否公开 |
| --- | --- | --- |
| 本仓库 | 源码、合成测试、图标、文档、构建脚本 | 可以 |
| 安装文件夹 `versions`、启动器、`channel.json` | 程序版本 | 可由干净构建发布 |
| 安装文件夹 `data/events-v1` | 私人论文修改记录 | 绝不提交 |
| `%LOCALAPPDATA%/PaperFlow` | 私人快照、备份、本机日志与设置 | 绝不提交 |
| `%LOCALAPPDATA%/PaperFlow/app-cache` | 校验后的本机程序缓存 | 无需提交 |
| `%LOCALAPPDATA%/PaperFlow/update-cache` | 自动更新下载的临时文件（校验通过后立即搬走） | 无需提交 |

源码仓库放在同步文件夹**以外**，避免多台电脑同步同一个 `.git`。其他电脑开发时使用各自的 Git clone。公开包由 Git 提交和干净构建生成，绝不压缩正在使用的安装目录。见 [开发与发布](docs/RELEASING.md) 和 [隐私边界](SECURITY.md)。

## 更新

开发者从同一个提交生成公开源码包、程序包，并可将该程序版本部署到个人的同步安装目录。数据目录不参与构建和部署。其他电脑收到新版后，从托盘完全退出，再打开原来的启动器即可切换。运行中的旧版不会被强行重启。

改名那一版把程序、启动器和本机目录一起换了名字。旧的启动器仍然可用，它会读同一份 `channel.json` 并启动新程序；旧版本机资料在首次启动新版时自动迁移。开机启动项会从 `PaperProgress` 改写到 `PaperFlow`。

更新有两种方式，互不影响：一是同步整个程序文件夹（自用那台默认走这条路，零联网），二是程序内自动更新。设置 → 同步与启动 → 更新提示可选“每次都提示 / 每天一次 / 不提示”，默认每天一次，旁边有“现在检查一次”。检查只读一份静态清单（`releases/latest/download/update.json`），是普通 GET，不带请求体、不带 Cookie、不带设备标识；发现新版后挂件底部出现一条提示，点“下载并安装”才会下载，下载后校验长度与 SHA-256，再写进 `versions/<版本>/` 并更新 `channel.json`，最后提示“重启并更新”。校验不过的文件会被删掉，不会覆盖现在的程序；选“不提示”则一次网络请求都不发。

启动器检查文件长度和 SHA-256，将程序复制到本机缓存后运行；新版未完整同步时优先使用已有的可用缓存版本。首次安装没有缓存时需要等待文件同步完整。哈希只检测传输损坏，不是数字签名；当前未提供代码签名。

git config core.hooksPath .githooks
dotnet build PaperFlow/PaperFlow.csproj
dotnet run --project tests/PaperFlow.Tests.csproj -c Release

## 阶段隐藏、优先级与翻页

默认隐藏当前在审论文。归类依据是最后一个已勾选阶段，未勾选时归入开题。例如勾选在审后隐藏，后来勾选返修则进入返修分组；不会因为历史上曾勾过在审一直隐藏。阶段隐藏不改变进度、不删除论文。

标题最左侧的三个点表示优先级：三点为高，两点为中，一点为低。点击圆点可在高、中、低之间切换，也可在论文资料里修改。旧论文默认为中。优先级随论文同步；隐藏阶段、优先级筛选、分页和字重只影响本机。

在“论文选项”选择需要显示的优先级以及暂时隐藏的阶段。三种翻页模式为不翻页、按优先级翻页（高→中→低）、按阶段分组翻页（第一页排除所选阶段，第二页只有所选阶段）。阶段分页时，所选阶段会被放到第二页而非全局隐藏。优先级筛选、搜索和原来的显示范围仍与分页叠加；选择过窄可能出现空页。可点“显示全部”恢复全览。

## 宣传图片

```powershell
./PaperFlow.Launcher.exe
# 开发环境中执行专门的合成数据导出：
dotnet run --project PaperFlow -- --promotional-assets "$env:TEMP/PaperFlow-promotion"
```

宣传导出分支只创建内置的虚构论文及临时目录，完全不加载正式资料、同步目录或桌面画面。输出五套 2 倍像素的真实界面图和 2880×1920 宣传 PNG，均标注虚构演示数据。正式发行包使用 `versions/<版本>/PaperFlow.exe --promotional-assets <输出目录>` 调用此分支。
